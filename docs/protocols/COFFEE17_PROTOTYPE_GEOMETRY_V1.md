## Literature and audit
- Khosla et al., Supervised Contrastive Learning, NeurIPS 2020, https://proceedings.neurips.cc/paper_files/paper/2020/hash/d89a66c7c80a29b1bdbab0f2a1a94af8-Abstract.html
- Qian et al., SoftTriple Loss, ICCV 2019, DOI 10.1109/ICCV.2019.00655. Multiple normalized centers per class; evidence is retrieval/clustering, not closed-set classification. The paper explicitly leaves classification evaluation to future work.
- Yao et al., Exploration of Class Center for Fine-Grained Visual Classification, IEEE TCSVT 34(10), 2024, DOI 10.1109/TCSVT.2024.3406443; preprint https://arxiv.org/abs/2407.04243. Class-center constraints and class-center-derived soft labels, direct FGVC precedent.
- Hu et al., Siamese networks for few-shot coffee bean defect detection, LWT 235 (2025) 118631, DOI 10.1016/j.lwt.2025.118631. Seven categories including sound; 3220 images, dataset available on request, not verified public. Do not compare pair classification to Coffee17 OOF.
- Code search on default branch is incomplete: active branch models.py contains ArcMarginClassifier. No completed multicenter geometry result found in ledger. Do not describe ArcFace as a novel method.
- Independent coffee dataset audit: USK-Coffee four categories; CBD nine grade categories (not same 17 defect taxonomy); Thai Robusta AL-ViT binary. Mendeley dataset DOI 10.17632/ffhdwp4428.1 reports 4038 images across 21 SNI classes, instance segmentation, but accompanying paper, grouping and crop feasibility not yet verified. No established independent full Coffee17-equivalent dataset. Oxford Flowers102 official dataset and split (https://www.robots.ox.ac.uk/~vgg/data/flowers/102/index.html) is a possible separate methodological benchmark, not external coffee validation.

Normalize embeddings. For each class K1 is normalized train centroid; K2 is deterministic spherical two-means, first seed nearest centroid, second most dissimilar to first, maximum 100 iterations, fail closed on empty cluster/degeneracy/nonconvergence. Predict validation class by largest cosine similarity to a class prototype. Compare K2 vs K1 (effect of multiple centers), show B0 linear as reference (different classifier). Record prototype occupancy, center cosine, train cohesion, paired rescue/damage, validation predictions, fold mean Macro/Hard/Worst-F1 and accuracy.
